# 찐맛 — 검증된 맛집만 (v0.1 데모)

구글 지도 기준 **리뷰 50개 이상 · 평점 4.5 이상**인 곳만 골라 보여주는 모바일 웹앱.

- `index.html` 단일 파일 (프레임워크·외부 요청 없음, 아티팩트/정적 호스팅 겸용)
- 기능: 카테고리 칩(10종) · 검색 · 정렬(평점/리뷰/거리) · 내 위치(geolocation)+동네 프리셋 ·
  주변 탭(거리·도보시간) · 찜(localStorage) · 매장 상세 바텀시트(메뉴/리뷰/구글지도 링크) · 다크모드
- 필터는 실제로 동작: 데이터 45곳 중 기준 미달 10곳 자동 제외

## 데이터
현재는 데모 데이터(가상 매장). 내일 연동 예정:
1. **Google Places API** — 실제 평점·리뷰 수·사진·영업시간으로 교체.
   `api/` 서버리스 함수로 키를 프록시 (Nearby Search → rating>=4.5 && user_ratings_total>=50 필터)
2. **Gemini API** — "AI 맛집 추천" 탭 활성화 (취향 입력 → 추천)

두 키 모두 PC에서 발급 후 Vercel 환경변수(`GOOGLE_PLACES_KEY`, `GEMINI_KEY`)로 주입 예정.
