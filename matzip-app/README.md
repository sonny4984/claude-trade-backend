# 찐맛 — 검증된 맛집만 (v0.5)

구글 지도 기준 **리뷰 50개 이상 · 평점 4.5 이상**인 곳만 보여주는 모바일 웹앱.
키가 없으면 데모 데이터, 키를 꽂으면 **실시간 구글 데이터**로 자동 전환됩니다.

## 구조
```
matzip-app/
  index.html   # 앱 전체 (단일 파일, 데모용 사진 내장)
  api/
    health.js  # 키 설정 여부
    search.js  # Places(New) 검색 + 4.5/50 필터 + 정규화
    place.js   # 상세 + 구글 리뷰(최대 5) + 영업시간
    photo.js   # 사진 프록시 (키 비노출)
    ai.js      # Gemini 추천 (구조화 출력 + 모델 폴백)
  build.mjs    # index.html → public/index.html (charset·viewport·PWA 래핑)
  public/      # 배포용 정적 결과물 (vercel이 서빙)
  SETUP.md     # 키 발급·배포 가이드
```

> `index.html`은 아티팩트용 조각(문서 head 없음)이고,
> 단독 배포는 `npm run build`로 만든 `public/index.html`을 씁니다.

## v0.5 추가
- **명소 연계**: 카페·공원·미술관 등도 같은 기준(4.5/50)으로 검증해 노출.
  홈에 "가볼 만한 명소" 선반, 상세에 **다음 코스로 어때요?**(밥 → 카페/명소, 도보순)
- **정렬 칩**: 평점순 / 리뷰 많은순 / 가까운 순을 항상 보이게
- **라이브 모드**: `/api/health` 자동 감지 → 실제 구글 평점·리뷰·사진·영업시간·전화
- **Gemini 추천**: 조건 3개 + 자유 입력 → 3곳 선정 + 매칭률 + 이유
