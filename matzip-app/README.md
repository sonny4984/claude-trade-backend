# 찐맛 — 검증된 맛집만 (v0.2 풀 데모)

구글 지도 기준 **리뷰 50개 이상 · 평점 4.5 이상**인 곳만 보여주는 모바일 웹앱.
`index.html` 단일 파일(외부 요청 0) — 프레임워크·SDK 없이 전부 직접 구현.

## v0.2 주요 기능
- **자체 캔버스 지도 엔진**: 한강·여의도까지 그린 서울 스타일 지도, 지역 클러스터 → 핀 전환,
  팬/핀치줌/더블탭/휠, 핀 탭 ↔ 하단 카드 레일 동기화, 내 위치 마커
- **AI 추천 탭(✨)**: 누구랑/기분/예산 3문항 → 온디바이스 스코어링으로 매칭률과 이유 칩과 함께 top3 추천
  (Gemini 연결 시 대화형으로 교체될 자리)
- 홈: 오늘의 픽(날짜 시드 로테이션 + 시간대 인사말) · 테마 컬렉션(혼밥/심야/데이트) · 최근 본 맛집
- 상세: 별점 분포 차트 · 리뷰 키워드 칩 · 메뉴/가격 · 방문자 리뷰 · 비슷한 곳 추천 · 공유(Web Share)
- 제스처: 당겨서 새로고침, 시트 드래그 닫기, 햅틱(지원 기기)
- 온보딩 3슬라이드, 검색 최근어, 테마 설정(시스템/라이트/다크), 해시 딥링크(#map #ai #p9)
- 필터는 실동작: 45곳 중 기준 미달 10곳 자동 제외
