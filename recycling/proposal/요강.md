# 인천 신정중 영어 영상 공모 — 요강

사진으로 받은 내용을 그대로 옮긴다. 해석이나 판단은 붙이지 않는다.

## 3. 영상 제작 안내

| | |
|---|---|
| 가 | 첫 화면에 반드시 포함할 내용: **영상 제목(영어), 학교명(영어)** |
| 나 | 영상 길이: 최대 **3분 이내** (3분을 초과하는 부분은 심사에서 제외) |
| 다 | 파일 형식: **mp4** |
| 라 | 파일명: **학교명_제목_대표학생이름.mp4** (ex) 인천신정중학교_Culture_KimJiyoon.mp4 |

### 마. 제작 언어 및 자막
1. 영상 내 모든 대사, 설명, 자막은 **영어**로 진행
2. 자막 글꼴 **굴림, 고딕, 명조체**만 사용 가능하며 기타 폰트는 불가
3. 자막은 **화면의 1/3을 넘지 않아야** 하며 **하단에 삽입**해야 함
4. **영어 설명 또는 영어 대사를 반드시 포함**해야 함 (영상 자체 녹음 / 후시 녹음)

## 4. 유의 사항 안내

| | |
|---|---|
| 가 | 영상은 학생들이 직접 기획·촬영·편집한 **순수 창작물**이어야 함 |
| 나 | 동영상의 **화질과 음량**을 사전에 확인하여 영상 내용이 잘 전달될 수 있도록 주의 |
| 다 | 타인의 작품을 **표절하거나 무단 도용 시 심사에서 제외 및 수상 취소** |
| 라 | 부적절한 언어, 장면, 표현은 사용 금지 |
| 마 | 초상권 및 저작권 침해 유의 — **모든 사진과 영상은 직접 촬영한 것만 사용**하며, 사람의 경우 **촬영에 동의한 사람만** 촬영하며, 동의가 없는 사람들은 **얼굴 부분을 모자이크** 처리해야 함 |
| 바 | 제출된 영상은 학교의 교육 목적 및 홍보에 활용될 수 있음 |
