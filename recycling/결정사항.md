# 4A 를 목소리로 만들었다 (2026-09-04)

어머님이 「4a는 우리가 목소리 만들어서 해야해」라고 하셔서 만들었다.

## 무엇으로 만들었나

처음에 Higgsfield 의 seed_audio 를 쓰려 했으나 크레딧이 없어 못 썼다
(0.8 크레딧/건인데 무료 플랜 잔액 0). 로컬에도 음성 합성 도구가 하나도
없어서 **piper** 를 설치하고 영어 여성 음성 모델 둘을 받았다.

  piper-tts (pip)
  en_US-amy-medium.onnx      63 MB
  en_US-lessac-medium.onnx   63 MB

로컬에서 도는 것이라 크레딧이 안 든다. 앞으로 영어 줄이 더 필요해도
같은 방식으로 만들 수 있다.

## 크기를 아이들 녹음에 맞췄다

| 아이 녹음 | LUFS |
|---|---|
| 1번 | -17.3 |
| 3번 | -16.5 |
| 5번 | -26.0 |
| 9번 | -25.3 |
| 14번 | -16.3 |
| 16번 | -16.6 |
| **가운뎃값** | **-17.0** |

piper 출력이 -17.2 로 이미 거의 맞았다. loudnorm 으로 -17 에 맞춰 두었다.

아이들 녹음 사이에도 크기가 -16.3 ~ -26.0 으로 10dB 벌어져 있다. 붙일 때
줄마다 맞춰야 한다.

## 후보 셋

아이들이 읽은 속도는 초당 약 2.3음절이다(3번이 21음절에 9.11초). 4A 는

# 임시판을 만들었다 (2026-09-04)

`out/임시판.mp4` 52.6MB · `out/임시판_미리보기.mp4` 27.2MB · 둘 다 2분 52초.

## 정해진 것

| | |
|---|---|
| 4A 목소리 | **2번** (amy 느리게, 9.19초). 1번은 빨라서 안 들린다고 하셨다 |
| 1-1 클로즈업 | **영상1 로 간다.** 페트병이 아니라 캔·파우치가 담겨 있다고 말씀드렸으나 그대로 가기로 정하셨다 |
| 세면대 순서 | A=①비우기 · C=②헹구기 · B=③라벨떼기. B 는 잰 값, A/C 는 화면으로 판단했다 |

B 가 라벨떼기인 것은 재서 확인했다. 파란 라벨 화소가 앞절반 0.17% →
뒷절반 0.01% 로 94% 사라진다. A 와 C 는 거의 변하지 않는다.
A/C 중 어느 쪽이 헹구기인지는 수도꼭지 언저리의 프레임 간 변화로 가려
보려 했으나 1.71 대 1.48 로 손떨림에 묻혀 판별이 안 됐다. 화면을 보고
A(병을 세면대에 거꾸로 기울임)를 비우기로, C(수도꼭지 앞에 세워 듦)를
헹구기로 잡았다.

  1. 나레이션 19개를 앞뒤 무음 떼고 -17 LUFS 로 맞춤 (build/nar/)
