# TOEIC 실전 모의고사 1 (간결 디자인 · 문제집/해설지 분리)

앞서 만든 **오리지널 RC 문항(Part 5·6·7, 100문항)**을 그대로 사용하되, 요청에 맞춰
① **문제집(문제만)** 과 **해설지(정답+상세해설)** 를 완전히 분리하고,
② 디자인을 **보내주신 Part 5 샘플처럼 간결하게**(흑백·세리프·2단, 컬러 배너 없음) 다시 구성했으며,
③ 해설을 **시중 교재 수준으로 상세하게**(해석·정답근거·보기별 오답분석·어휘) 작성했습니다.

| `TOEIC_실전모의고사1_해설지.pdf` | 채점·**복습용** | 정답표(101–200) + 문항별 상세 해설 |

## ✍️ 해설 구성 (시중 해설지 형식)

- **Part 5** — 각 문항: `정답` · `해석`(문장 번역) · `해설`(정답 근거·문법 포인트) · `보기`(A~D 전 보기 ○/✕ 오답분석) · `어휘`
- **Part 6·7** — 세트별 **지문 전체 해석** + 문항별 `정답`·`해설`(지문 근거)

## 🎨 디자인

- 흑백, 세리프체(Noto Serif), 상단 파트명 + 밑줄만 — 컬러 배너/문서 칩 제거
- Part 5 **2단** 배치, 지문은 얇은 테두리(문서 라벨 없음) — 샘플과 동일한 간결함

## 🖨 재빌드
```bash
cd src
python3 build_clean.py   # 문제집·해설지 PDF 생성 (Chromium headless)
```
```
src/
  render_clean.py   # 간결 디자인 렌더러(문제집/해설지)

  data_p5.py        # Part 5 (상세해설 포함)

```
