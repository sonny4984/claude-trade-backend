# TOEIC RC 실전 문제집 (신규 창작)

실제 TOEIC Reading(RC) 시험의 구성·유형·난이도를 반영해 **100% 새로 창작한** 실전 문제집입니다.
회사명·상황·문장·지문을 전부 오리지널로 제작했으며(기존 자료를 그대로 옮기지 않음), 시중 문제집 수준의
퀄리티와 **오류 0**을 목표로 전 문항을 검산했습니다.

## ✅ 오류 검산 방법

1. **단일정답 설계** — 각 문항은 정답이 하나만 성립하도록 작성하고, 오답은 명확히 배제(복수정답 소지 배제).
2. **수동 재풀이** — 100문항을 직접 다시 풀어 정답을 확정.
3. **자동 구조검사** (`src/verify.py`) — 보기 4개 · 보기 중복 없음 · 빈칸/근거 존재 · 번호 연속(101–200) ·
   해설 유무 · 정답 인덱스 유효성 → **오류 0건**.
4. **근거 명시** — Part 7 전 문항의 정답 근거를 지문 인용과 함께 해설에 표기, 연계추론의 계산·논리 검증.
5. **분포 점검** — 정답이 한쪽 보기로 치우치지 않는지 확인.

## 🖨 재빌드

```bash
cd src
python3 verify.py     # 자동 검산 (실패 시 종료코드 1)
python3 build.py      # 문제집·해설집 PDF 생성 (Chromium headless)
```

### 소스 구조

## ⚠️ 안내
실제 TOEIC의 구성·유형을 참고해 **학습용으로 새로 창작한 콘텐츠**이며, ETS의 실제 시험 문제가 아닙니다.
TOEIC은 ETS의 등록 상표입니다.
