# TOEIC Part 5 — 정답 검산 & 해설지

업로드된 **최신 Part 5 문제 자료**의 정답을 다단계로 검산하고, 자체 완결형 **해설지 PDF**를 제작한 결과물입니다.
정확도를 최우선으로, 문항별 정답을 독립적으로 재풀이한 뒤 원본 정답과 대조하고 자동 스크립트로 구조 무결성을 전수 검사했습니다.

## 📦 결과물 (PDF)

| 파일 | 대상 자료 | 문항 | 정답 검증 방식 | 분량 |
|---|---|---|---|---|
| `토익응급실_최신Part5_검산해설_90문항.pdf` | 토익응급실 260228·260329·260426 | 90 | **원본 제공 정답과 100% 대조 일치** | 16쪽 |
| `최서아_Part5_100제_정답해설.pdf` | 최서아 [서아 PT] 100제 2탄 | 100 | 원본 정답 미제공 → **자체 풀이·확정** | 17쪽 |

각 해설지는 **문장(빈칸) + 보기 4개(정답 강조) + 정답 배지 + 유형 태그 + 한글 해설 + 어휘**로 구성된 자체 완결형입니다.

## ✅ 검산(檢算) 방법 — 4단계

1. **독립 재풀이**: 190문항을 하나하나 직접 풀어 정답을 산출.
2. **원본 대조**: 정답이 포함된 토익응급실 90문항은 원본 하단 정답과 전수 대조 → **90/90 일치**.
3. **자동 구조검사** (`src/verify.py`): 보기 4개 · 빈칸 존재 · 보기 중복 · 번호 순서 · 해설 유무 · 정답 인덱스 유효성 → **오류 0건**.
4. **분포 점검**: 정답이 특정 보기에 치우치지 않는지 확인(계통 오류 방지).
   - 토익응급실: 260228 A8/B7/C6/D9 · 260329 A9/B9/C8/D4 · 260426 A6/B7/C7/D10
   - 최서아 100제: A21/B28/C26/D25

## 🔎 발견 사항 (투명 공개)

- **원본 지문 오탈자** (정답에는 영향 없음, 배포 전 수정 권장)
  - 토익응급실 260228 #102: `We provides` → `We provide`/`It provides`
  - 토익응급실 260329 #116: `making well suited` → `making him/her well suited`
- **복수정답 소지 문항**
  - 최서아 #96: `need + to be p.p.`(정답 C)와 `need + -ing`(B)이 모두 수동 용법으로 성립 → 해설에 명시.

## 🖨 재빌드

