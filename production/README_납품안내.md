# 오늘 먹은 간식이 내 집중력을 바꾼다? — 혈당 스파이크와 뇌 과학의 비밀

기획서(콘티/스토리보드)에 따라 제작한 **3분 인포그래픽 애니메이션 + 썸네일** 납품 패키지입니다.

## 1. 납품 파일

| 파일 | 규격 | 비고 |
|---|---|---|
| `혈당스파이크와_뇌과학의_비밀_FHD.mp4` | 1920×1080 (FHD) · H.264 · 30fps · AAC 256kbps | 본편, 정확히 3분 00초 |
| `thumbnail.jpg` | 1920×1080 (FHD) · JPEG | 썸네일 |
| `혈당스파이크와_뇌과학의_비밀.srt` | UTF-8 자막 34컷 | 영상에 자막이 이미 삽입되어 있으며, 재편집·번역용으로 함께 제공 |

## 2. 기획서 대비 구현 내역

섹션 경계를 **기획서 콘티의 타임코드에 그대로 고정**했습니다.

| 기획서 구성 | 기획서 타임코드 | 실제 영상 | 구현 화면 |
|---|---|---|---|
| 도입부 (문제 제기) | 00:00 ~ 00:45 | **00:00 ~ 00:45** | 타이틀 → 밤 책상·창밖 야경 → 간식 등장 → 학생이 회색 유령처럼 흐려지는 연출 → `왜?` → 시한폭탄 + "혈당 스파이크" |
| 전개부 (과학적 원리) | 00:45 ~ 01:45 | **00:45 ~ 01:45** | 혈당 그래프가 실시간으로 그려지며 급상승(SPIKE)→급락(CRASH) · 혈관 단면에 포도당(노랑)이 쏟아지고 인슐린(하늘)이 투입되어 치우는 애니메이션 · 뇌 연료 차단 · `2% / 20%` 인포그래픽 |
| 심화부 (뇌 과학) | 01:45 ~ 02:30 | **01:45 ~ 02:30** | 뇌 단면 → 시상하부 스포트라이트 · 오렉신 스위치가 `ON → OFF` 로 전환되고 각성도 게이지가 100%→24% 로 하강 · 정제당 vs 통곡물·견과류 곡선 비교 |
| 결론 및 제언 | 02:30 ~ 03:00 | **02:30 ~ 03:00** | 카드뉴스 3장(간식 교체 / 거꾸로 식사법 1‑2‑3 / 완만한 곡선) → 엔딩 타이틀 |

기획서의 나레이션 문장은 **한 문장도 빠짐없이 그대로 사용**했고, 각 구간의 길이를 채우기 위해
문장 사이를 잇는 설명을 보강했습니다(뇌의 에너지 소비 비중, 인슐린 과다분비, 오렉신 세포 연구 등).

## 3. 제작 방식

- **영상**: 기획서가 요구한 "2D 모션그래픽 중심의 인포그래픽 애니메이션"에 맞춰, 모든 장면을
  벡터(SVG/CSS) 기반으로 **직접 렌더링**했습니다. 스톡 영상이나 템플릿을 쓰지 않았으므로
  화면 전체가 이 영상만의 오리지널 그래픽입니다. 5,400 프레임을 1프레임씩 결정론적으로
  캡처해 인코딩하여 흔들림·프레임 드랍이 없습니다.
- **나레이션**: 한국어 TTS로 생성한 뒤 문장 사이 호흡을 구간별로 자동 조절해 각 섹션의
  타임코드에 정확히 맞췄고, EQ → 컴프레서 → **-16 LUFS 라우드니스 정규화**까지 마스터링했습니다.
- **발음 검증**: 완성된 나레이션을 **음성인식으로 역전사해 원본 대본과 대조**했습니다.
  4개 구간 평균 일치율 **98.4%** (심화부 100%)로, 오독 없이 정확히 읽혔음을 확인했습니다.
  검증 결과는 `speech_check.json` 에 남아 있습니다.
- **BGM·효과음**: 저작권 분쟁 소지를 없애기 위해 **직접 신디사이즈**했습니다(64마디, 84BPM,
  Am–F–C–G). 휘익(전환)·팝(등장)·임팩트(강조)·클릭(스위치)·파워다운(각성 저하) 등
  효과음도 모두 합성 제작이며, 나레이션이 나올 때 BGM이 자동으로 낮아지는
  **사이드체인 더킹**을 적용했습니다.
- **자막**: 나레이션과 프레임 단위로 동기화된 타이포그래피 자막 34컷을 화면에 삽입했습니다.

## 4. 저작권 안내

- BGM·효과음: 본 프로젝트를 위해 새로 합성한 오리지널 음원입니다. **별도 저작권료 없음.**
- 그래픽: 전부 직접 제작한 벡터 그래픽입니다. 썸네일 배경 이미지는 생성형 AI로 제작했습니다.
- 폰트: **Pretendard** (SIL Open Font License 1.1) — 상업적 이용 가능.

## 5. 수정 요청 대응

원본 프로젝트 파일이 모두 포함되어 있어 다음 수정은 빠르게 가능합니다.

| 수정 항목 | 방법 |
|---|---|
| 문구·자막 수정 | `script.json` 수정 → `build_timeline.py` → `render.py --video` |
| 색상·레이아웃 | `scene.html` 의 CSS 변수(`--red`, `--cyan` 등) 수정 |
| 썸네일 카피 | `thumbnail.html` 수정 → `render_thumb.py` |
| BGM 분위기 | `bgm.py` 의 `PROG`(코드 진행)·`BPM` 수정 |

```bash
python3 process_audio.py     # 나레이션 마스터링 (섹션별 목표 길이에 자동 정렬)
python3 verify_speech.py     # 발음 검증 (음성인식 역전사 대조)
python3 build_timeline.py    # 타이밍·자막 큐 생성
python3 bgm.py               # BGM·효과음 합성
python3 render.py --video    # 본편 프레임 렌더링
python3 mux.py               # 최종 합성
python3 render_thumb.py      # 썸네일
python3 make_srt.py          # 자막 파일
```
