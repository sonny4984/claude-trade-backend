## 🖨 다시 빌드하기

콘텐츠는 `src/` 아래 파이썬 데이터로 관리되며, 하나의 소스에서 문제집·해설집을 함께 생성합니다.

```bash
cd src
python3 build.py     # HTML 생성 후 Chromium(headless)으로 PDF 렌더
```

필요 도구:
- `python3` (표준 라이브러리만 사용)
- Chromium (`/opt/pw-browsers/chromium`) — HTML → PDF 변환
- 한글 폰트 `Noto Sans CJK KR` (해설집 렌더링)

### 소스 구조

```
src/
  render.py           # 렌더링 엔진(CSS·레이아웃·문제집/해설집 조립 함수)
  build.py            # 데이터 취합 → HTML 생성 → PDF 렌더 (엔트리포인트)
  data_p5.py          # Part 5 문항 데이터
  data_p6.py          # Part 6 지문·문항 데이터
  data_p7_single.py   # Part 7 단일지문
  data_p7_double.py   # Part 7 이중지문
  data_p7_triple.py   # Part 7 삼중지문
```

각 문항은 `no`(번호), `opts`(보기 4개), `ans`(정답 인덱스 0–3), `type`(유형 태그),
`expl`(한글 해설), 선택적으로 `opt_why`(보기별 해설)·`vocab`(어휘)를 가집니다.

## ⚠️ 안내

본 모의고사는 실제 TOEIC 시험의 **구성과 유형을 참고해 학습용으로 창작한 콘텐츠**이며,
ETS의 실제 시험 문제가 아닙니다. TOEIC은 ETS의 등록 상표입니다.
