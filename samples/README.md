# 기획안 시안

`proposal/` 의 기획안 세 편이 화면에서 어떻게 보이는지 미리 보여주는 40초 시안.
클라이언트가 어느 안을 고를지 정할 때 쓴다.

## 다시 만들기

```bash
cd samples
python3 render.py --stills 2,12,27,38   # 정지컷 검수 (세 편 모두)
python3 render.py --video               # 무음 영상 3편 (약 4분 30초)
bash finish.sh                          # BGM·효과음 합성 후 붙이기
```

결과물은 `out/` 에 나온다. 40.00초 · 1920x1080 · 30fps · 48kHz 스테레오 AAC.
`out/` 은 git 에 넣지 않는다. 위 두 줄이면 똑같이 다시 나온다.

## 시안에 들어가는 것과 안 들어가는 것

공모 요강이 「모든 사진과 영상은 직접 촬영한 것만 사용」을 요구하므로,
실제 출품 영상의 실촬 화면은 학생이 찍어야 한다. 시안이 담는 것은 그래픽 쪽이다.

- 첫 화면(제목 + 학교명) — 학교명은 `○○중학교` 로 두었다
- 측정값 카드, 막대그래프, 식 대입 애니메이션
- 자막 스타일 — 나눔고딕, 한 화면 10자 이내, 하단 고정 위치
- 좌상단에 콘티 칸 이름과 본편 타임코드를 띄워 기획안과 대조할 수 있게 했다

실촬이 들어갈 자리는 점선 액자에 촬영 지시문을 얹어 표시한다.

## 폰트

요강이 자막 글꼴을 굴림·고딕·명조로 제한하므로 **나눔고딕**을 쓴다.
컨테이너가 초기화되면 다시 깔아야 한다.

```bash
apt-get install -y fonts-nanum
```

`production/` 의 혈당 영상이 쓰는 Pretendard 는 여기서 쓰지 않는다.

## 구조

- `scene.html` — `?s=1|2|3` 으로 편을 고른다. `render(t)` 가 t 초의 화면만 보고
  그리므로 몇 번을 돌려도 같은 결과가 나온다. 난수도 시각도 쓰지 않는다.
- `render.py` — Playwright 로 프레임을 캡처해 x264 로 인코딩한다.
- `bgm.py` — BGM 과 효과음을 넘파이로 직접 합성한다. 외부 음원이 없어
  저작권 문제가 없다. 시안 3 의 신발 미끄러지는 소리는 `scene.html` 의
  이징을 거꾸로 풀어 각도가 25·29·33·39도가 되는 시각에 맞춰 넣는다.
- `finish.sh` — 소리를 만들고 영상에 붙인다.

## 주의

- `bgm.py` 의 loudnorm 은 내부에서 샘플레이트를 올린다. `-ar 48000` 을 빼면
  96kHz 로 나와서 재생기에 따라 문제가 생긴다.
- 시안 3 의 경사판은 최대 41도까지 기운다. 판 길이 880, 받침점 (380, 760) 이면
  판 끝이 (1044, 183) 이라서 우상단 수식 상자(x 1120 부터)와 부딪히지 않는다.
  판 길이나 각도를 키우면 겹치므로 함께 확인해야 한다.
