# 공모전 기획안

`과학영상_공모전_기획안_3편.docx` 를 만드는 곳. 기획안 세 편과 별지(세 안 비교표,
공모 요강 준수 사항)가 한 문서에 들어간다.

## 다시 만들기

```bash
cd proposal
npm install          # docx 패키지 (루트 package.json 과 분리돼 있다)
node build_docx.cjs
```

내용은 `plans.json` 에 있다. 문구만 고칠 때는 이 파일만 손보면 된다.
문서 형식(제목 박스, 1~5번 절, 콘티 타임코드)은 클라이언트가 준 원본
기획서를 그대로 따랐다.

`plans.json` 구조는 `{"plans":[...3편...], "annex":{...별지...}}` 이고,
콘티(`s4`) 한 칸은 `[제목, 영상, 나레이션, 자막]` 네 칸짜리 배열이다.
자막은 요강이 요구하는 한 화면 10자 제한에 맞춰 미리 끊어 적어 둔다.

## 숫자 검증

정확성이 100점 만점에 50점이라 콘티에 적은 수치는 계산으로 확인한 값이다.

- 그네 진자: 유효 길이 2.0m 에서 T = 2π√(L/g) = 2.838초, 10왕복 28.4초.
  1.2m 로 줄이면 22.0초. 진폭 45도면 등시성이 깨져 4% 길어져 29.5초.
  역산 g = 4π²L/T² = 9.79. 스톱워치 반응오차 0.2초는 10왕복 기준 0.7%.
- 온도 지도: 적외선 온도계가 재는 것은 기온이 아니라 표면 온도다.
  같은 보도블록에서 건물 그늘과 나무 그늘을 비교해야 증산작용 몫이 분리된다.

수치를 고칠 때는 세 곳이 서로 맞는지 확인한다. 제목의 숫자, 2번 절의 원리 설명,
4번 절 콘티의 나레이션과 자막.

## 주의

- `docx` 라이브러리는 문단 테두리를 top → bottom → left → right 순으로
  내보내는데 워드 스키마는 top → left → bottom → right 를 요구한다.
  네 방향을 다 쓰면 문서가 깨지므로 위아래 선만 쓴다.
- 별지 표의 열 너비 합계는 본문 폭과 같아야 한다. A4 11906 에서 좌우 여백
  1000 씩 빼면 9906 이고, `COLS` 합계를 여기에 맞춰 두었다.
- 이 컨테이너의 LibreOffice 는 텍스트 파일조차 열지 못해 렌더 확인이 안 된다.
  대신 `validate.py` 로 스키마를 검사하고, `document.xml` 을 직접 파싱해
  문단 수와 표 구조를 확인했다.
